Analysis Logic & Gemini Integration # ------------------------------------------------------------------------------ def generate_ai_analysis(ticker: str, market_data: dict, target_price: float, user_intent: str) -> str: """Invokes Google Gemini SDK to analyze stock data and produce strategic insights.""" if not HAS_GENAI: return "Error: `google-genai` SDK is not installed. Evaluate the following stock analysis request and generate a clear structured output. ### Market Context & Parameters: - **Stock Ticker**: {ticker} - **Current Market Price**: {market_data['price']:,} KHR - **24h High**: {market_data['high']:,} KHR - **24h Low**: {market_data['low']:,} KHR - **Volume**: {market_data['volume']:,} - **P/E Ratio**: {market_data['pe']} - **P/B Ratio**: {market_data['pb']} - **User's Desirable Price**: {target_price:,} KHR - **User's Intent**: {user_intent} ### Instructions: 1. Provide a breakdown under the following exact section titles: - **Real-time Data Summary** - **Fundamental Valuation Analysis** (Evaluate P/E and P/B ratios against general frontier market expectations and company book value) - **Technical & Price Margin Analysis** (Calculate the safety margin percentage: ((Desirable Price - Market Price) / Market Price) * 100, and evaluate the target price vs intraday High/Low range) - **Final Strategic Verdict** (Clear action plan tailored to the user's intent: {user_intent}) """ try: response = client.models.generate_content( model="gemini-2.5-flash", contents=prompt, config=types.GenerateContentConfig( temperature=0.3 ) ) return response.text except Exception as e: return f"An error occurred while communicating with Gemini API: {str(e)}" # ------------------------------------------------------------------------------ # 5.
